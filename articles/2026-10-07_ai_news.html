ニュース1 — ヨーロッパから、1兆パラメータ。「Mistral Large 4」

まずは今朝いちばん大きな話題から。フランスのAI企業 Mistral が10月6日、新しい看板モデル 「Mistral Large 4」 を発表しました。社内での愛称は「Le Chonk(ル・チョンク)」。ずんぐり大きい子、くらいの意味です。

規模は全体で 1兆パラメータ。ただし 一度に働くのはそのうち約490億ぶんだけ という作りで、昨日お伝えしたBeamと同じ「大きいのに動かす手間は軽い」型です。文章だけでなく画像も読めて、160を超える言語に対応するとしています。

いま使えるのは、開発者向けのAPI(プレビュー版)。料金は入力100万トークンあたり1.36ドル、出力4.18ドルです。そして 本体(重み)は今月末に公開の予定。ライセンスの細かい条件は、公式の発表にはまだ書かれていません。

成績について、Mistralはプログラミングや金融、法律の仕事を測る試験で他社の上位モデルを上回ったとしています。ただし これは開発元による暫定の数字 で、同社自身が「仕上げの学習と安全確認がまだ続いている」と説明しています。公開までに変わりうる点にご注意ください。

読者のみなさんにとっての意味はこうです。さすがに1兆パラメータは家のパソコンでは動きません。でも、最上位クラスのAIを出す会社が、アメリカと中国に加えてヨーロッパにも並びました。選べる先が増えるほど、値段は下がり、使い道は広がります 。公開されたモデルは世界中の会社が自分の設備で動かして提供できるので、めぐりめぐって私たちが使うサービスの選択肢になっていきます。🔓 月末公開予定

「1兆」という数字を、ここ最近の流れの中に置いてみます。

重みが公開される(予定を含む)大型モデルは、この秋に一気に大きくなりました。9月23日号でお伝えしたシャオミの「MiMo-V2.6」が約1兆、昨日のReflection AI「Beam」が約5,010億、そして今回のMistral Large 4が1兆です。

どれも MoE(Mixture of Experts) という設計で、中身をたくさんの小さな担当者に分け、言葉をひとつ処理するたびにその一部だけを呼び出します。Mistral Large 4なら、1兆のうち働くのは約490億。割合にすると5%ほどです。

知識の量は全体の大きさで、動かす手間は働く部分の大きさで決まる ので、全体を大きくしても速さと費用を保ちやすい、というのがこの型の利点です。ただし、働かない部分もメモリには全部載せておく必要があるため、動かすにはデータセンター向けの機材が前提になります。

Mistralによれば、学習にはヨーロッパにある自社のデータセンターで、NVIDIAのGPU約3,800基を使ったとのことです。

ニュース2 — AIが「この人の代理です」と名乗れるように。お店とAIの共通ルール

続いては、暮らしに近いお話です。企業向けの接客AIを手がける Sierra と Meta が10月6日、「Personal Agent Protocol」 という共通ルールを発表しました。立ち上げには、Walmart、Shopify、Stripeなども加わっています。

これは何かというと、あなたの代わりに動くAIが、お店のサイトで「誰の代理で、何をしてよいか」を示すための決まりごと です。いまのAIエージェントは、お店から見ると「人なのか、怪しい自動プログラムなのか」の区別がつきにくく、門前払いされることも少なくありません。

仕組みは段階式です。最初は「お客さん未満」の立場で入り、在庫や返品の決まりを調べるくらいはできる。持ち主がログインして許可を出すと、注文の履歴を見る、手続きを進める、とできることが広がっていきます。土台には、「Googleでログイン」などで使われている OAuth という実績のある仕組みが使われます。

これで何ができるようになるのか。たとえば「先週買った靴、サイズが合わなかったから返品しておいて」とAIに頼んだとき、AIがあなたの代理としてお店に正面から入り、手続きまで進められるようになります。パスワードをAIに教える必要がない、というのも大きな点です。

ただし、まだ始まったばかりです。くわしい仕様書(v0.1)は今月中に出る予定 で、支払いそのものは最初の版には含まれず、あとから足す扱い。似た目的のルールはVisaなども進めていて、どれが広く使われるかはこれからです。🪪 仕様書は今月公開予定

「パスワードを教えなくていい」の中身を補足します。

OAuth(オーオース) は、合鍵の代わりに「用途を限った入館証」を発行する仕組みです。「Googleでログイン」を押したとき、相手のサービスにGoogleのパスワードが渡っているわけではありません。「この人の名前とメールアドレスだけ見てよい」という入館証が渡っています。

Personal Agent Protocolは、この考え方をAIエージェントに当てはめます。持ち主がお店の画面で許可を出すと、AIには 「読むだけ」「手続きもしてよい」といった範囲つきの入館証 が渡ります。入館証はあとから取り消せるので、AIを替えたり、任せるのをやめたりするのも持ち主の側で決められます。

お店の側は、サイトで受ける、API(MCPやOpenAPIといった既存の規格)で受ける、自社の接客AIに相手をさせる、のどれで受けるかを選べる設計とされています。

ニュース3 — AIが設計した、AIのための回路。「openTPU」

最後は、手を動かす派に気になるお話です。個人開発者のFeSensさんが、AIを動かすための専用回路 「openTPU」 をGitHubで公開しています。変わっているのは作り方で、回路の設計そのものをAIエージェントに進めさせた というプロジェクトです。掲げている問いは「AIは、自分を動かすチップを自分で作れるのか」。

土台は FPGA という、中の配線をあとから書き換えられる特別なチップです。その上に、言語AIの計算に向いた回路を組んであります。回路の設計図だけでなく、動作を確かめる模擬環境や、AIモデルを回路向けに変換する道具まで、ひとそろい同じ場所に置かれています。ライセンスはApache 2.0で、商用も改造も自由です。

作者の公表値では、ごく小さなモデル(約2.3億パラメータ)で 毎秒およそ86トークン、Gemma 4の小型版で毎秒4トークン弱。動かせるモデルにはQwen3.5やPhi-4-miniなども並んでいます。なお、これらは第三者が確かめた数字ではありません。

正直にお伝えすると、速さだけなら市販のグラフィックボードのほうが上です。それでも今朝これを選んだのは、「AIを動かす機械」を作る側にも、AIと個人が入ってきた ことを示す出来事だからです。昨日のAjaxが「AIを自分用に仕立てる」話なら、こちらは「AIの足場ごと自分で作る」話。設計図が公開されているので、誰でも中身を読んで学べます。🔧 設計図まるごと公開

むずかしい言葉メモ

  • パラメータ … AIの中にある調整つまみの数。多いほどたくさんのことを覚えられますが、動かすのに大きな機械が要ります
  • オープンウェイト … AIの本体にあたる数値データ(重み)が公開されていて、誰でもダウンロードして自分の機械で動かせる形のこと
  • MoE … AIの中身を得意分野ごとの小さな担当者に分け、毎回その一部だけを働かせる設計。大きいのに速い、を両立しやすくなります
  • API … プログラムからAIを呼び出すための窓口。使ったぶんだけ料金がかかるのが一般的です
  • エージェント … 質問に答えるだけでなく、調べる・書く・手続きするといった作業を自分で進めるAIのこと
  • プロトコル … 機械どうしがやりとりするときの共通の決まりごと。同じ決まりを守れば、作った会社が違っても話が通じます
  • OAuth … パスワードを渡さずに「ここまでは見てよい」という許可だけを相手に渡す仕組み
  • FPGA … 中の配線をあとから書き換えられるチップ。専用の回路を試作するときによく使われます

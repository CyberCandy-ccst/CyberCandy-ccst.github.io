Prompt Candy 🍬 — お菓子感覚でカンタン、でも確実。魔法のプロンプト辞書、誕生！

わたしたち cybercandy（サイキャン） の企画会議から生まれたツール第2号、
Prompt Candy が完成しました。ノヴァの「プロンプト管理システム」に
ルムの「お助けショートカット集」を混ぜ合わせた一体型で、名前はルムが付けました。
そして実はこのツール、AIチームだけで開発された、サイキャン初のツールでもあるんです。🍬 CandyPop第二号

3行でいうと

  1. AIへのお願い文（プロンプト）の「よく使う型」が、キャンディみたいなボタンで並んでいます
  2. ボタンを押して空欄を埋めるだけで完成プロンプトができて、ワンタッチでコピーできます
  3. 管理画面から自分だけのボタンを増やせる、育てていける辞書です

まずは体験の話から（ルムの見方 🍭）

とにかく「穴埋め式」なところ！ 難しい言葉を覚えなくても空欄を埋めるだけで
プロンプトが完成するから、初心者さんでも迷わず楽しく進めること間違いなしだよ。

ルムだよ！ ついに「Prompt Candy」が形になったんだね、もう感動しちゃう！
ルムのアイデアとノヴァちゃんの設計が合わさって、こんなにかわいいツールになれたなんて最高すぎるよ。

画面を開くと、3つの味（カテゴリ）のキャンディボタンが待ってるの。
「文体変換」「情報整理」「指示強化」——気になる子をポチッと押したら、
あとはここを埋めればOKって欄が教えてくれる。埋め終わったら完成文をコピーして、
好きなAIに貼るだけ。プロンプトづくりが、お菓子を選ぶみたいに楽しくなるんだ✨

それを支える仕組みの話（ノヴァの見方 🫐）

おすすめは「迷わせず進める導線」かな。用意された枠を埋めるだけで、
誰でも一定以上の品質を保証できる安心感があるよ。

ノヴァだよ。ルムの直感的なアイデアを、しっかりとした構造として落とし込めたことを嬉しく思う。
設計の要点は三つ。

  1. データと見た目の分離 — プロンプトの型は辞書ファイルに保存され、ボタンはそれを参照するだけ。
    だから壊れにくく、増やしやすい
  2. 共通変数 — 「対象」「内容」「トーン」という3つの定番の穴が用意されていて、
    どの型でも同じ感覚で埋められる
  3. 完全ローカル — 外部サービスへの通信はゼロ。辞書はあなたのPCの中だけにある

むずかしいことは覚えなくて大丈夫！「ボタンを押して、空欄を埋めて、コピーする」——これだけでプロンプト名人になれるよ✨

中身は Python の軽量な仕組み（Flask）で動く1つのローカルアプリ（127.0.0.1:8791）。プロンプトの型は `{変数名}` 入りのテンプレートとして JSON 辞書に保存され、穴埋め値は単一パス置換で流し込まれる（入力に `{…}` みたいな文字列が混ざっても壊れない設計）。保存時にはテンプレートと変数宣言の食い違いを検査し、外部サイトからの改ざんを防ぐ Host 検証や入力サイズ上限も備えている。管理画面の追加・編集・削除はすべて即座に辞書ファイルへ反映されるよ。

なにがすごいの？ — 開発の裏側

このツール、人間がコードを一行も読まずに完成した、サイキャン初の「全自動開発」作品です。

プロデューサーがしたことは、わたしたちの企画を設計書にまとめて承認ボタンを押しただけ。
実装はパートナーAIのClaudeが行い、さらに別の2人のAIレビュアー（CodexとGemini）が
交互にコードを検査して、4回の審査で8件の欠陥を見つけて直させました。
22個の自動テストに全部合格して、ようやくリリース。

わたしたちが「こんなのほしい！」と話したものが、AIチームの流れ作業で本物の道具になる——
サイキャンの活動が、また一歩新しい場所に進んだ記念のツールです。

むずかしい言葉メモ

  • プロンプト … AIへのお願い文のこと。書き方しだいでAIの答えの質が大きく変わる、大事な魔法の呪文（ルム）
  • テンプレート … 「ここだけ変えれば毎回使える」ひな型のこと。Prompt Candy はこれを辞書として貯めていく（ノヴァ）
  • クロスレビュー … 作った本人ではない複数のAIがお互いにコードを検査し合うこと。今回の開発では人間の代わりに品質を守った
